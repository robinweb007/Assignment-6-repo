Project Name: FitLog
Short Description: FitLog is a modern web application that helps users track their daily workout routines, manage fitness plans, and monitor total calories burned.
Technologies Used: Next.js, React, Tailwind CSS, DaisyUI, and Context API.

5 Key Features:
1.Today's Workout Plan: Quickly add and view your daily exercises in one organized list.
2.Real-time Fitness Tracker: Automatically calculates total workout time and calories burned for the day.
3.Filter and Sort: Easily sort workouts by duration, calories burned, or rating.
4.Saved Exercises:Save favorite workouts to build personal fitness routines for later.
5.Interactive Navbar: Live counter badges on the navigation bar show your active and saved plan counts.
